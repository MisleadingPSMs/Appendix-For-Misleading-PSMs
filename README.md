# Anonymous Supplementary Materials
This repository contains supplementary materials for our paper submission.

## Contents
- `Phase1_List_of_Websites.pdf` - List of selected websites that met our inclusion criteria for Phase 1
- `Phase1_Prompts_for_GPT4.1.pdf` - Prompts used for GPT-4.1 API analysis in Phase 1
- `Phase2_Codebook.pdf` - Codebook for qualitative analysis in Phase 2
- `Phase2_Survey_Form.pdf` - Survey instrument used in Phase 2
- `Phase2_Variable_Table.pdf` - Variable definitions and coding used in the quantitative analysis in Phase 2
