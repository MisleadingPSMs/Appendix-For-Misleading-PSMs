# Mixed Signals, Unequal Weight: How Users Integrate Password Strength Ratings Across Websites

Supplementary materials for the paper submitted to USENIX Security 2027.

## Contents

- **Phase1_List_of_Websites.csv**: Websites screened in Phase 1 and whether each was included in the PSM measurement.
- **Phase1_Prompts_for_GPT4.1.pdf**: Prompts used for semantic-category refinement and classification in Phase 1.
- **Phase1_Semantic_Categories.pdf**: The 17 semantic categories and representative examples used in password generation.
- **PSM_Study_Passwords.csv**: The 32 synthetic passwords used in the user study and their benchmark classifications.
- **Phase2_SurveyForm.pdf**: Survey instrument used in the Phase 2 user study.
- **PSM_Participant_Exclusions.pdf**: Data-quality screening criteria and exclusion counts.
- **Qualitative_Codebook.pdf**: Qualitative codebook and question-level frequencies for open-ended responses.
