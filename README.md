This repository contains materials accompanying the submitted paper on how users respond to password-strength ratings across websites.

## Files

- **PSM_Study_Survey.pdf**  
  Survey instrument used in the user study. Dynamic password and PSM-rating values are shown as placeholders.

- **PSM_Website_List.xlsx**  
  Websites included in the Phase 1 PSM measurement.

- **PSM_Study_Passwords.csv**  
  The 32 synthetic passwords used in the user study and their benchmark classes.

- **PSM_GPT4_1_Prompts.pdf**  
  Prompts used during the semantic-category refinement and classification step.

- **PSM_Participant_Exclusions.md**  
  Participant exclusion criteria and counts.

- **PSM_Qualitative_Codebook.md**  
  Question-specific qualitative codes and frequencies used in the paper.

## Notes

The benchmark classification was used for password selection and analysis and was not shown to participants. All study passwords are synthetic.

The survey contains condition-specific sections. Individual participants saw only the questions associated with their assigned condition and any applicable display logic.
